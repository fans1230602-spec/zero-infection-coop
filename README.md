# 末日：零号感染 — 双人实时联机网页版

## 已实现
- 创建6位房间码，第二台手机输入房间码加入（最多2人）
- WebSocket 双人实时同步行动、地点、血量、体力、敌人血量、基地库存和队伍聊天
- 搜索物资、背包、休息、饮水、治疗、开关门、探索、战斗
- 断线后同一浏览器可凭本地保存的身份重新加入
- 手机适配的中文暗色界面

## 本地运行
安装 Node.js 18 或更新版本，然后在项目目录执行：

```bash
npm install
npm start
```

浏览器访问 http://localhost:3000 。同一 Wi-Fi 下手机可通过电脑的局域网 IP 和端口 3000 访问（需允许防火墙访问）。

## 公网部署（Render 示例）
1. 将整个项目上传到你自己的 GitHub 仓库。
2. 在 Render 创建 **Web Service**，连接该仓库。
3. Runtime 选 Node，Build Command 填 `npm install`，Start Command 填 `npm start`。
4. 部署成功后获得 HTTPS 地址；两个玩家分别用手机打开相同网址。
5. 玩家1创建房间，将6位房间码发给玩家2；玩家2输入房间码加入。

**注意**：免费实例可能休眠。当前版本房间数据保存在 Node 进程内存中，服务重启会丢失房间；没有数据库持久化、跨实例共享、用户账号或正式的防作弊系统。推荐先在单实例服务上体验。服务器没有部署前，不能跨网络联机。
